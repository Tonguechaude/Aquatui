# Aquatui

Ce projet est un terminal aquatique en Rust avec Ratatui. Il permet de se détendre dans un environnement aquatique virtuel lors que l'on est trop énervé car notre code ne compile pas.
Si vous êtes anxieux lors de période de dev intensif, vous pouvez vous détendre en regardant les poissons !

Avant de me dire que je perd mon temps à réinventer la roue, je vous invite premièrement à regarder les poissons puis dans un second temps à vous dire que je suis juste un étudiant qui aime bien Rust et qui essaye de prendre en main Ratatui !

Ce projet est une honteuse copie du projet existant Asciiquarium en Perl. [disponible ici](https://github.com/cmatsuoka/asciiquarium.git)

## Installation

Pour installer ce projet, vous devez avoir Rust et Cargo installés sur votre machine. Vous pouvez les installer en suivant les instructions sur le site officiel de Rust : https://www.rust-lang.org/tools/install.

## Utilisation

Une fois le projet installé, vous pouvez lancer l'application en exécutant la commande suivante dans le répertoire du projet :

```bash
cargo run
```
## Développement

Pour développer ce projet, vous pouvez utiliser les commandes suivantes :

```bash
cargo build
cargo test
```
